All eligible PNGs passed structure/chunk verification, decoding, metadata-dimension checks and the shared preprocessing. ZIP reads also check entry CRC. Excluded PNGs were inventoried but not decoded. Patient completeness is assessed using all metadata-listed images across the available sources, before PA/AP and quality filtering.

Raw data and identifiers stay local. Source PNG hashes are recorded only in the local manifest. The cache uses the same per-image preprocessing and patient split seed as the original experiment. More data does not by itself establish improved model performance; the next training run must measure it. The original test cohort remains exploratory, and aggregate scores on an expanded test population are not directly comparable to the old aggregate.
